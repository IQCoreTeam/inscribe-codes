LINKS ARE UPDATED AT DEPLOY
We inscribe each media file, then rewrite the json's image (and animation_url) from the local name / your url to the on-chain gateway url of that inscription, then inscribe the json too. the NFT link points at the inscribed json. attribute values are plain text, left as is; any asset url found anywhere is rewritten the same way; an external website link (external_url) is kept. so your original links are only a staging reference, the minted token resolves fully from chain.
